# SaaS Polabooth

Application web du loueur : événements, éditeur de designs, galeries photo et suivi des bornes
(React, Vite, Supabase).

Présentation du projet : [README à la racine](../README.md). Installation d'une instance :
[docs/installation-instance.md](../docs/installation-instance.md). Détails techniques :
[CLAUDE.md](CLAUDE.md).

## Commandes

| Commande | Rôle |
|---|---|
| `npm run install-instance` | Installe une instance (base, fonctions, compte admin, build) |
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production (`dist/`) |
| `npm test` | Tests (runner natif de Node) |
| `npm run lint` | ESLint |
